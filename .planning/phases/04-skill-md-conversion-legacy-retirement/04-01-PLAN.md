    Import only Python standard library modules (re, sys, pathlib, argparse, dataclasses,

    so extract the frontmatter with a regex on the leading fenced block rather than a YAML parser.
    Define a `LintResult` dataclass with fields `file`, `check`, `passed`, `message`.
    Implement one soft check per record (append a result, never raise, so one file's failure
    does not abort the run):

      - frontmatter block present (leading fenced block extracted);
      - `name` length ≤ 64; `name` charset is lowercase letters / digits / hyphens only;
        `name` contains neither reserved word ("claude", "anthropic");
        `name` exactly equals the parent directory name (D-07);
      - `description` non-empty and length ≤ 1024;
      - frontmatter contains no literal angle-bracket characters;
      - FMT-02 body-line advisory: warn (do not fail) if the body exceeds 500 lines.
    Resolve the target by walking `Path(root).rglob("SKILL.md")` under the given path, guarding
    file reads with `except OSError`. Provide `main()` with a positional `path` argument and a
    `--format json|text` flag (JSON to stdout, human summary otherwise), returning exit code 0 when
    every check passed and 1 when any check failed. Mirror `quick_scan.py`'s docstring "Design rules"
    block, restating the stdlib-only rule and the purpose (verifies SKILL.md frontmatter against the
    Agent Skills spec FMT-01/02/05). Keep it ~40-60 lines of logic; do not over-engineer file-walking.
