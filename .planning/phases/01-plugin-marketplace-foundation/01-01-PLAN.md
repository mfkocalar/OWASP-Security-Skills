## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public GitHub repo → Claude Code plugin loader | Untrusted static manifest JSON crosses here; validated by `claude plugin validate` (JSON schema + type checks) |
| marketplace catalog → end-user install | The github `source` object determines which repo/code a user actually installs from |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing | marketplace.json `name` / source resolution | medium | mitigate | Choose a marketplace `name` not on Anthropic's reserved-names list; lock the exact `owner/repo` in a github source object (D-04) so there is no typosquat/ambiguity — asserted in Task 2 verify |
| T-01-02 | Elevation of Privilege | plugin.json component declarations | low | mitigate | Declare no hooks, no mcpServers, no custom commands — skills-only via the default `skills/` scan; minimizes executable attack surface by design (Task 1 action) |
| T-01-03 | Repudiation / Tampering (trust signal) | plugin.json version / repository / homepage | low | mitigate | Honest `0.1.0` pre-1.0 version (D-02) plus real `repository`/`homepage` URLs pointing at the verified origin, not placeholders (Task 1) |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager installs occur in this plan — it authors two static JSON files only; the Package Legitimacy Gate does not apply (01-RESEARCH.md §"Package Legitimacy Audit") |
