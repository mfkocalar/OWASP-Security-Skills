<threat_model>
This is a documentation/content-migration plan; threats are content-integrity /
credibility risks for a public security reference, not runtime appsec.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OWASP official source -> shipped reference | Upstream 2025 edition text/mapping is transcribed into top10.md and owasp-urls.json; a wrong transcription becomes shipped misinformation |
| Reference content -> end-user reviews | Downstream users act on this guidance during their own security reviews; stale/wrong IDs mislead them |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | top10.md / owasp-urls.json edition note | high | mitigate | Record only `2025 (Final)`; source = OWASP GitHub README verified FINAL in 02-RESEARCH.md via unmediated curl (D-04 gate). Do not cite RC-era blog posts. |
| T-02-02 | Tampering | top10.md category headers/mapping | high | mitigate | Build every category from TOPIC per 02-RESEARCH.md mapping table (never numeric find-and-replace); per-category name+ID acceptance greps in Task 1; manual topic-diff per 02-VALIDATION.md before verify. |
| T-02-04 | Information Disclosure | owasp-urls.json source URLs | medium | mitigate | Use official owasp.org/Top10/2025 URLs from 02-RESEARCH.md §Sources; best-effort `curl -sI` liveness; record `retrieval_date` (D-05). |

No package-manager installs occur in this plan (content-only), so no supply-chain
(T-*-SC) legitimacy checkpoint applies.
</threat_model>
